# README photos and display evidence

Published with the owner's permission. These images come from the actual unboxing and a recorded MINDYLAB demonstration on the G2 display. They are not generated product imagery or synthetic UI mockups.

| Public file | What it shows | Processing |
|---|---|---|
| `g2-unboxing.jpg` | Opened package and protective case | Orientation corrected; resized to 1600 × 1200; re-encoded without identifying metadata |
| `g2-glasses.jpg` | G2 glasses after unboxing | Cropped and resized to 1600 × 1200; re-encoded without identifying metadata |
| `mindylab-input-1.png` | Recorded native screen with input count 1 | Exact 810 × 810 pixel crop; saved as lossless RGB PNG |
| `mindylab-input-2.png` | Recorded native screen with input count 2 | Exact 810 × 810 pixel crop; saved as lossless RGB PNG |

No AI retouching, generated text, sharpening or reconstruction was used. The natural blur and optical appearance of the recorded display are retained. Screenshot crops contain no phone status bar, navigation hint, Gallery controls or thumbnail strip. Photo selection avoids identifying labels and faces.

EXIF/GPS, capture timestamps, camera/phone identifiers, XMP, IPTC, comments and embedded thumbnails were removed. Raw JPEG markers and PNG chunks were checked as well as decoded metadata. [media-audit.json](media-audit.json) records the dimensions and hashes of the public derivatives only. Original images and private processing records were not uploaded.

These frames illustrate the native display and changing counter. USB-free operation, persistence and display restoration are separate tested behaviors described in the main project story; a still image alone does not establish those properties.
